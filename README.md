# Minecraft 基岩版模组编辑器

一个强大的Web编辑器，用于创建和编辑Minecraft基岩版的模组（MOD）。支持行为包和资源包的完整开发工作流。

## ✨ 核心功能

### 📁 项目管理
- **新建项目** - 快速创建新的Mod项目，自动生成行为包和资源包框架
- **导入项目** - 导入现有的 `.mcaddon`、`.mcpack` 文件
- **保存/加载** - 将项目保存到浏览器本地存储，支持项目持久化
- **撤销/重做** - 完整的历史记录管理，支持快捷键 `Ctrl+Z`/`Ctrl+Y`

### 🎯 快速创建向导
提供多种模板选项，快速创建常见的游戏元素：

#### 实体 (Entities) - `Ctrl+Alt+E`
- 基础实体 - 标准实体模板
- 带速度实体 - 包含移动组件的实体

#### 物品 (Items) - `Ctrl+Alt+I`
- 基础物品 - 标准堆叠物品
- 工具物品 - 带耐久度的工具物品

#### 方块 (Blocks) - `Ctrl+Alt+B`
- 基础方块 - 标准方块模板
- 液体方块 - 液体类型方块

#### 配方 (Recipes) - `Ctrl+Alt+R`
- 有形配方 - 标准合成配方模板

### 📝 高级编辑器
- **CodeMirror 集成** - 专业的代码编辑体验
- **JSON 语法高亮** - 自动识别和高亮JSON语法
- **实时验证** - JSON 格式实时检查，错误提示
- **全屏编辑** - `Ctrl+F11` 全屏编辑模式
- **代码补全** - `Ctrl+Space` 自动补全建议
- **注释快捷键** - `Ctrl+/` 快速切换代码注释
- **智能缩进** - 自动缩进和格式化

### 🔍 搜索和浏览
- **文件树** - 可视化的项目文件结构浏览
- **文件搜索** - 快速搜索文件名
- **内容搜索** - 在所有文件中搜索特定文本
- **快速预览** - 纹理实时预览，JSON 可视化编辑

### 🔧 工具和验证
- **项目信息** - 实时显示项目统计信息
  - 文件总数、JSON数、纹理数
  - 已修改文件计数
  - 行为包/资源包状态
- **结构校验** - 深度的JSON和Manifest结构验证
- **项目配置** - 统一管理项目配置
  - 最小引擎版本
  - 格式版本

### 📦 导出和打包
支持多种导出格式：
- **MCADDON** - 完整的Mod包（行为包+资源包）
- **MCPACK (行为包)** - 仅行为包
- **MCPACK (资源包)** - 仅资源包

### 🎨 资源管理
- **纹理上传** - 直接上传PNG/JPG纹理文件
- **纹理预览** - 实时预览纹理效果
- **批量操作** - 支持文件重命名、删除、复制路径

## 🚀 使用指南

### 第一步：创建项目
1. 点击"新建项目"按钮
2. 输入项目名称
3. 系统自动生成行为包和资源包

### 第二步：添加内容
1. 使用快速创建按钮或快捷键添加实体/物品/方块
2. 选择模板类型
3. 输入ID (小写字母、数字、下划线)
4. 编辑器自动生成对应的JSON文件

### 第三步：编辑文件
1. 从文件树中双击打开文件
2. 在编辑器中修改内容
3. 实时JSON验证
4. 保存自动更新

### 第四步：验证和导出
1. 点击"校验结构"检查所有文件
2. 选择导出格式
3. 点击"导出下载"生成包文件
4. 将文件导入Minecraft中使用

## 💾 数据存储

项目数据存储在浏览器的 localStorage 中，包括：
- 项目结构和文件内容
- 纹理图片（Base64编码）
- 项目配置信息
- 命名空间设置

**注意**: 清除浏览器缓存会删除所有保存的项目，建议定期导出备份。

## 🔧 技术栈

- **前端框架**: 纯JavaScript + HTML5
- **代码编辑器**: CodeMirror 5.65
- **打包库**: JSZip 3.10
- **文件处理**: FileSaver.js 2.0
- **验证**: JSONLint 1.6

## 📋 文件结构

### 行为包 (Behavior Pack)
```
behavior_pack/
├── manifest.json
├── entities/       # 实体定义
├── items/          # 物品定义
├── blocks/         # 方块定义
├── recipes/        # 合成配方
└── scripts/        # 脚本文件
```

### 资源包 (Resource Pack)
```
resource_pack/
├── manifest.json
├── entity/         # 实体客户端定义
├── textures/       # 纹理资源
├── models/         # 模型文件
├── render_controllers/  # 渲染控制器
└── shaders/        # 着色器
```

## 🐛 常见问题

**Q: 项目数据会随浏览器缓存删除吗？**
A: 是的，清除浏览器数据会删除所有项目。建议定期导出。

**Q: 支持多人协作吗？**
A: 目前不支持。可以通过导出/导入文件来共享项目。

**Q: 编辑的JSON文件有大小限制吗？**
A: 没有严格限制，但编辑器性能可能在极大文件上受影响。
